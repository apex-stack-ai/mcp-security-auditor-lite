# MCP Security Auditor Lite — Free Claude Skill

Audit your MCP server deployments for security vulnerabilities. Scan for tool description injection, permission scope issues, and supply chain risks.

## What This Does (Lite — 3 of 8 Dimensions)

1. **Tool Description Integrity** — Detect injection attacks, hidden instructions, and Unicode evasion in tool descriptions
2. **Permission Scope Analysis** — Identify over-privileged tools, missing least-privilege boundaries, and dangerous capability combinations
3. **Supply Chain Risk** — Assess server origin trust, version pinning, and dependency risks

## Quick Start

1. Download the `.skill` file from this repo
2. Install in Claude
3. Share your MCP config (JSON or describe your setup)
4. Get a security audit with risk scores and remediation steps
